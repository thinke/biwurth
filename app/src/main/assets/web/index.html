Themes

A theme is a zip: colours, these settings, a background, pictures (SVG too) for Empty space tiles and page templates. Picking one under Theme above puts its look on the layout; save to show it.

Background

The grid is stretched over the whole screen, so the layout fits any resolution. Changing it scales the tiles to the new grid.

MQTT device

Makes the tablet a device in Home Assistant (MQTT discovery): screen switch, brightness, page, battery, last touch and more.

Data sources

Where tiles get their data: Home Assistants and biwurth's own sources, as many of each as needed. The primary Home Assistant's entities keep their own ids (sensor.x); another Home Assistant's are src.<source>.sensor.x, and an own source's fields src.<source>.<field>.

Presence

Wakes the panel when someone moves in front of it, and keeps it awake while they do. Calibrate once where the panel hangs: step 1 with nobody in view, step 2 while you walk in front of it. Camera frames are looked at on the tablet and dropped; nothing is kept or sent.

    What this tablet has

      Benchmark

      Measures how smoothly the panel draws, on the tablet: the screen wakes and, for the time set, is left alone, redrawn in full every frame, or swiped between pages. “Warm” keeps the CPU and GPU busy with a speck of drawing every frame, to see if that helps.

      Backup

      Everything set here: pages and tiles, Home Assistant, MQTT, cameras and screen settings, in one file. The website key is never included.

      Then keep the file somewhere private: it opens your Home Assistant.

      Restore

      Replaces the settings in the file. A file without the token or password keeps the ones the tablet has.

      Set up a new tablet

      Makes a factory-reset tablet a biwurth panel, device owner included, without adb or a Google account. On the tablet's first "Welcome" screen, tap six times in the same spot, connect to Wi-Fi if it asks, and scan this code. Android downloads biwurth from GitHub and checks it's signed with this panel's key. Then restore a backup here.

      With Wi-Fi in the code the tablet connects by itself; the password is then readable by anyone who scans it.

      Updates

      This tablet runs Android 11 or older and biwurth isn't device owner, so Android asks for every update: updates are shown here and in Home Assistant, but you install them yourself.

      Releases come from github.com/thinke/biwurth. Each download is checked against its SHA-256 and the installed app's signing key. A device-owner panel installs without asking; otherwise Android asks on the tablet (on Android 12+ only the first time).

      Log

      biwurth's own log, kept on the tablet: connections, camera and source errors, updates and crashes. The newest 500 lines, newest last.
